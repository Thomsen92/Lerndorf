## Runtime and export

Cards embed one front/back atlas, maximum 1024 × 768. Motifs are closed geometry with no external texture dependencies. Own joins between card, medallion and miniature are deliberate. Reimport checks compare native geometry, dimensions, materials, UVs and both printed faces; artistic acceptance stays with the user.

SVGs reference standard system fonts without distributing their files. The website uses the local Comic Neue under its included SIL Open Font License. Three.js and its loaders retain the MIT license in `vendor/LICENSE`. Blender is an authoring tool and is not distributed. The catalog contains no learner records, ownership state or unlock logic.
