# Spielsprache Deutsch / Englisch

Nutzerauftrag: Englisch als neuer Standard, Deutsch vollständig erhalten, Umschalten in den Einstellungen. Ein Agent, keine Änderung von Datenbank, RPCs, IDs, Lernlösungen oder dem Namen Lerndorf. Lehrerbereich bleibt deutsch.

1. [x] Zentrale Frontend-Übersetzungen mit unveränderten deutschen Ausgangstexten und sicheren Platzhaltern. Sprache pro Browser speichern; Englisch ohne gespeicherte Wahl.
2. [x] Schülertexte in UI, Tutorial, Fehlermeldungen, Canvas-/3D-Beschriftungen und Anzeigenamen anbinden. Nutzernamen, freie Nachrichten und Aufgabenantworten nicht übersetzen.
3. [x] Einstellungen um English / Deutsch ergänzen. Wechsel lädt die Oberfläche mit erhaltener Anmeldung neu; keine Fortschrittswerte schreiben. Interne Berlin-Datumsberechnung beibehalten, nur Datumsanzeige umstellen.
4. [x] Vorhandene Tests explizit für den deutschen Kompatibilitätsmodus erhalten; neue Prüfungen für englischen Standard, Speicherung, Platzhalter/HTML und unveränderte Protokollwerte hinzufügen. Beide Sprachen im Browser prüfen.

Keine neue Übersetzungsbibliothek, keine Datenbankmigration, kein automatisches Deployment.
