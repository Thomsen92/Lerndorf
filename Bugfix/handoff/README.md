# Fix-Pakete

Hier liegt pro beauftragtem Fehler **ein** Paket `FIX-xx.md`. Es ist so
geschrieben, dass eine frisch gestartete KI im Repo `Lerndorf` es ohne
Rückfragen ausführen kann.

Jedes Paket enthält:

1. Auftrag in einem Satz
2. Kontext (was der Nutzer sieht, warum es wichtig ist)
3. Betroffene Dateien / Hinweise
4. Randbedingungen (CLAUDE.md, RPC, keine Schülerdaten …)
5. Reihenfolge der Schritte
6. Test- und Abnahmekriterien
7. Was **nicht** geändert werden darf

Nach dem Fix trägt die Fix-KI in `BUGS.md` den Status und eine kurze
Änderungsnotiz ein. Die Lehrkraft nimmt ab.
